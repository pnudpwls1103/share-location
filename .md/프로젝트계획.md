### 🎯 MVP (필수)

1. GPS 위치 수집
2. Photon Fusion 기반 위치 실시간 동기화
3. 3D 지구본 위에 유저들의 위치 표시
4. 두 유저 간 거리 계산 및 표기
5. 링크 공유로 룸 초대 (딥링크)
6. 화면 캡처 후 이미지 저장/공유

### ⭐ 확장 기능 (차차 구현)

1. 멀티 유저 (N명) 위치 동시 표시
2. 유저 선택 → 거리 계산
3. 감정표현 이모지 UI (Photon으로 브로드캐스트)
4. 텍스트 채팅
5. 간단한 반응(하트, 박수, 웃음 등)

### 플로우
```
[앱 실행]
     ↓
[로그인/닉네임 입력]
(간단하게 '닉네임만' 입력)
     ↓
[메인 화면]
 - '친구 초대 링크 생성' 버튼
 - '참여하기' → 딥링크 자동 입장
 - 내 위치 GPS 갱신 ON
     ↓
[룸 생성]
 - Photon 룸 생성
 - 딥링크 복사
     ↓
[룸 입장]
 - 다른 유저 GPS 실시간 표시
 - 3D 지구본 상에 핀 배치
 - 거리 계산 UI 출력
     ↓
[유저 인터랙션]
 - 특정 유저 선택 → 거리 계산
 - 감정표현(임티) 전송
 - 채팅 메시지
 - 반응(이모지) 표시
     ↓
[기능 사용]
 - 화면 캡처 → 갤러리 저장
 - 공유하기
     ↓
[퇴장 / 종료]
 - Photon 룸에서 나가기
 - 앱 종료
```
